 Internal Security Audit: Botium Toys

## Project Overview
I conducted a comprehensive security audit for **Botium Toys** to assess their current assets and determine which security best practices are required to improve their posture.

## Scope and Goals
* **Scope:** The audit includes the entire security program: employee equipment (laptops, desktops, smartphones) and the internal network.
* **Goals:** Assess existing assets and identify which controls need to be implemented for better protection.

## Methodology
I categorized security controls into three specific domains to ensure a defense-in-depth approach:
* **Administrative/Managerial:** Policies and procedures defining employee roles and data management.
* **Technical:** Digital solutions including firewalls, IDS/IPS, and encryption.
* **Physical/Operational:** Physical security such as badge readers and surveillance cameras.
