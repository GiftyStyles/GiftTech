# Incident Report: Network Traffic Analysis

## Project Overview
I analyzed network traffic logs to investigate a connectivity issue where users could not access a specific domain. Using `tcpdump`, I identified a DNS failure that was preventing successful web requests.

## Technical Skills Used
* **Traffic Inspection:** Analyzed raw `tcpdump` logs to identify protocol failures.
* **Network Troubleshooting:** Identified **UDP port 53** as unreachable via **ICMP** error messages.
* **Incident Documentation:** Drafted a professional report summarizing findings and root causes.
